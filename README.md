One funny line, 103 characters: the excuse a robot vacuum gives after eating a sock.

> The sock looked at me funny, so I did what any self-respecting vacuum would do: I inhaled the evidence.

## Run it

```sh
python3 main.py
```

It validates the line (one line, at most 200 characters) and writes it to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR`.
